# Removing the extension

The extension stores no settings, no cache and no data, so removing it leaves nothing behind.

## With the Extensions app
1. Open **Extensions**.
2. Find **gnome_uninstall_app** → click **Remove** (or switch it off).

## With Files
1. Press `Ctrl+H` to show hidden folders.
2. Go to **Home → .local → share → gnome-shell → extensions**.
3. Delete the `gnome_uninstall_app@local` folder.
4. Log out and log back in.

Applications that were already removed using the extension stay removed.
Apps removed via the extension can be reinstalled normally from your distro or Flatpak/Steam.
(AppImages are moved to the Trash and can be restored from there.)
